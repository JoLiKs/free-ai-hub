# Free AI Hub — версия 2 ✨

Статический сайт без сборки и без зависимостей: чат с бесплатными AI-моделями **прямо из браузера**. Ключи **не нужны** (поле «свой ключ» — по желанию). Интерфейс на русском, тёмная и светлая темы и неоновый режим «Кибер-панк».

> Версия 1 лежит в соседней папке `free-ai-hub/` и не менялась. Всё новое — здесь.

## Запуск

Сайт состоит из ES-модулей (`<script type="module">`) и Web Worker для локальной модели, поэтому открывать `index.html` двойным кликом (`file://`) **не рекомендуется**: во многих браузерах модули при этом блокируются (в приложении есть подсказка на этот случай). Нужен любой статический http-сервер:

```bash
cd free-ai-hub-v2
python3 -m http.server 8138        # затем откройте http://127.0.0.1:8138
# или: npx serve .   /   php -S 127.0.0.1:8138
```

Подойдёт любой статический хостинг (GitHub Pages, Cloudflare Pages, Netlify, ZeroDeploy…): достаточно скопировать папку как есть, сборка не нужна.

> ℹ Старый деплой `rough-shape-307.zerodeploy.app` заблокирован хостингом (HTTP 451) — повторная выгрузка (30.09.2026, 03:55) приняла архив (HTTP 200), но сайт по-прежнему отдаёт 451. Живой демо-ссылки на v2 нет: запускайте локально или выложите папку на свой хостинг.

> ⚠ **Pollinations** зависит от адреса сайта (Origin): с одних адресов отвечает, с других — 402/403. Это поведение их сервера, а не приложения; при сбое приложение автоматически переключится на другую модель.

### Особые режимы

| Режим | Что это |
|---|---|
| **В браузере (WebGPU/WASM)** — 3 модели | SmolLM2 135M (~180 МБ), SmolLM2 360M (~390 МБ), Qwen2.5 0.5B (~790 МБ). Библиотека transformers.js (jsDelivr) и веса (Hugging Face) скачиваются **один раз по подтверждению** (диалог с размером), дальше работает офлайн, промпты никуда не уходят. Проверено в headless Chrome на WASM (~20 с на ответ SmolLM2-135M); **реальный GPU не тестировался**. Модели крошечные — качество низкое, это скорее демонстрация |
| **Kilo Gateway (через ваш CORS-прокси)** | бесплатные модели Kilo (≈15, в т.ч. `kilo-auto/free`) отвечают без ключа (~200 запр./час на IP), **но не отдают CORS-заголовки**, поэтому напрямую из браузера не работают. Для них есть необязательный `proxy/worker.js` (Cloudflare Workers, бесплатно): разверните и вставьте адрес в «Настройки → CORS-прокси». Без прокси эта группа просто не используется и **в счёт «40 моделей» не входит**. Модели Kilo могут обучаться на ваших промптах. Проверено: локальный Node-прокси + реальные ответы в интерфейсе; на Cloudflare сам воркер не разворачивался |

## Возможности v2

- **Чат**: потоковый ответ (SSE, любые разрывы чанков, `[DONE]`), блок «Размышления» (свернуть/развернуть) для `reasoning`/`reasoning_content`/`<think>`, стоп (Esc), «Заново», правка последнего сообщения (↑), копирование, системные промпты-пресеты, температура, лимит токенов, оценка токенов.
- **Markdown без зависимостей и безопасный**: заголовки, списки, цитаты, таблицы, ссылки (`rel="noopener noreferrer nofollow"`, только http/https/mailto), инлайн-код, блоки кода с языком, лёгкой подсветкой и кнопкой «Копировать». Картинок и сырого HTML нет; тест на XSS в репозитории.
- **Надёжность**: повтор при 429/502/503/504/402 с экспоненциальной паузой и **видимым обратным отсчётом**, `Retry-After`; очередь и лимитер на провайдера (для OVH — 2/мин/модель); таймауты (общий и «нет данных»); в режиме сравнения запросы идут со сдвигом; для AI Horde (шлюз oai.aihorde.net сам опрашивает задачу) при остановке соединение закрывается — отменяет ли шлюз саму задачу у волонтёров, не проверялось; понятные сообщения по статусам (401/402/403/404/429/5xx, CORS/сеть).
- **Автовыбор рабочей модели**: при сбое приложение переключается на следующую живую бесключевую модель и говорит об этом («⤳ переключено с …»). Отключается переключателем.
- **Проверка доступности**: кнопка проверяет модели крошечным запросом, ставит бейджи «работает / лимит / нестабильно / не работает» и кэширует результат на 6 ч. Списки моделей тоже кэшируются (TTL 6 ч) и обновляются с сервера.
- **Выбор модели**: поповер с поиском, избранным, фильтрами (Все / Избранные / Работают) и бейджами; Ctrl+K.
- **История чатов** в `localStorage`: несколько чатов, закрепление, поиск (по названию и тексту), переименование, удаление, экспорт в Markdown/JSON, импорт JSON; последний чат восстанавливается после перезагрузки.
- **Картинки (vision)**: скрепка/вставка/перетаскивание (до 3 изображений, сжимаются до 1024 px). Кнопка появляется, только если выбранная модель понимает картинки: у OVHcloud это Qwen2.5-VL-72B, Qwen3.8-27B, Qwen3.6-27B, Qwen3.5-9B (значок 👁; проверено curl'ом 30.09.2026 — «Red» на красный квадрат; в UI проверено на Qwen3.5-9B) и у «своего» эндпоинта (на вашу ответственность). Картинки **не сохраняются** в истории/экспорте (только пометка), чтобы не переполнять localStorage; автопереключение при сбое выбирает только vision-модели.
- **Озвучка ответа** (кнопка «Озвучить»): встроенный Web Speech API браузера, всё локально. В headless Chrome голосов нет, поэтому звук не проверялся — только что кнопка не ломает страницу.
- **Сравнение двух моделей** рядом (второй провайдер/модель — в боковой панели).
- **Дизайн**: тёмная тема + светлая (переключатель в шапке и в настройках; режима «как в системе» нет), аватары, индикатор набора, пустой экран с примерами запросов, адаптивная вёрстка (боковая панель-drawer, safe-area), уважение `prefers-reduced-motion`, фокус-стили, `aria-live`. Проверено axe-core: 0 нарушений в тёмной и светлой темах.
- **⚡ Кибер-панк** (кнопка «Кибер-панк» в шапке, работает на десктопе и мобильных): неоновый стиль маджента/циан/жёлтый на тёмно-фиолетовом фоне — анимированная сетка и сканлайны, срезанные углы, глитч логотипа, неоновая рамка поля ввода, терминальный код, кибер-индикатор набора, стилизованные скроллбары. Включается поверх тёмной темы, выбор сохраняется и применяется без вспышки; выключение возвращает прежнюю тему (авто/тёмная/светлая). Анимации отключаются при `prefers-reduced-motion`. Реализовано чистым CSS (`:root.cyber` в `style.css`) без внешних шрифтов. Скриншоты: `screenshots/cyber-*.png`.
- **Горячие клавиши**: Enter/Shift+Enter, Esc, Ctrl+K (модель), Alt+N (новый чат), `/` (поле ввода), Alt+B (панель), ↑ (править последнее).

## Как добавить провайдера

В `js/providers.js` добавьте объект в `PROVIDERS`. Для OpenAI-совместимого API достаточно:

```js
{ id: 'my', name: 'Мой API', short: 'Мой', group: 'keyless', type: 'openai', keyMode: 'none',
  baseUrl: 'https://example.com/v1', defaultModel: 'my-model',
  tags: ['без ключа'], speed: 'fast',
  hint: 'Описание для панели',
  limits: { concurrency: 2, rate: { max: 10, perMs: 60000, per: 'provider' } },   // клиентский ограничитель
  staticModels: ['my-model'],                                                     // запасной список
  parseModels(json) { return json.data.map(m => ({ id: m.id, label: m.id })); }   // необязательно
}
```

Затем проверьте `node tests/candidates.mjs` (CORS!) и `node tests/health.mjs --provider my`. Если `group: 'keyless'`, провайдер попадёт в автовыбор при сбоях (`FALLBACK_ORDER`) и в общую проверку.

## Необязательный CORS-прокси (`proxy/`)

`proxy/worker.js` — Cloudflare Worker (~60 строк): пересылает запросы **только к белому списку** (сейчас — Kilo Gateway), добавляет CORS, ничего не хранит, не подставляет ключи; можно ограничить сайты переменной `ALLOWED_ORIGINS`. Развёртывание: `cd proxy && npx wrangler deploy`. Локальная проверка без Cloudflare: `node proxy/local-test.mjs` (порт 8787) и в приложении укажите `http://127.0.0.1:8787`. Приложение работает и без прокси. Не превращайте воркер в открытый прокси и не используйте для обхода ограничений сервисов.

## Приватность

- Запросы идут напрямую из вашего браузера к выбранному сервису; собственного сервера у приложения нет, аналитики нет.
- Бесплатные сервисы **могут логировать** запросы. **AI Horde — запросы видят волонтёры.** Бесплатные модели Kilo могут обучаться на промптах. Не отправляйте личное, пароли и ключи.
- История чатов, настройки и ключи — в `localStorage` вашего браузера («Сбросить» — в настройках).
- Режим «В браузере» — единственный, где текст не покидает устройство; при первом запуске он скачивает библиотеку с jsDelivr и веса с Hugging Face.

## Известные ограничения

- Сервисы бесплатные и нестабильные: списки, лимиты и доступность меняются. Числа выше — на 30.09.2026.
- OVH: лимит 2/мин/модель общий с другими пользователями вашего IP/сети — 429 частые; приложение ждёт/переключает, но это не «мгновенный» ответ.
- Pollinations зависит от Origin; AI Horde медленный и без потоков; режим «В браузере» — слабые модели, WebGPU на реальном железе не тестировался.
- Браузеры: проверено в Chrome 154 (headless) и Firefox (Playwright, чат/markdown/поповер моделей); Safari/WebKit не проверялся (в песочнице нет зависимостей).
- Groq, Gemini и «Свой эндпоинт» не тестировались с реальными ключами (ключей нет).
- Код из ответов модели **не исполняется**; markdown безопасен, но ссылки из ответа ведут на внешние сайты — проверяйте.
