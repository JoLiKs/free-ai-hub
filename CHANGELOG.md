# Changelog

## v2.0 (2026-09-30)

### Новое
- **Архитектура**: монолитный `app.js` (~680 строк) разбит на ES-модули в `js/` (без сборки). Юнит-тесты (`tests/`), живой health-check, проверка кандидатов.
- **Провайдеры**: LLM7 — 4 бесключевые turbo-модели (было 2); AI Horde — актуальный список с живой статистикой очередей (22–23 модели); OVH — фильтр только чат-моделей; **режим «В браузере»** (transformers.js в Web Worker, 3 модели, opt-in с предупреждением о размере); **Kilo Gateway через необязательный CORS-прокси** (`proxy/worker.js`).
- **Чат**: блок «Размышления» для reasoning-моделей; markdown с таблицами, списками, цитатами, безопасными ссылками, блоками кода (язык, подсветка, «Копировать»); «Заново», правка последнего сообщения, стоп (Esc); пресеты системного промпта; температура и лимит токенов; оценка токенов.
- **История**: несколько чатов в `localStorage`, поиск, закрепление, переименование, удаление, экспорт Markdown/JSON, импорт; восстановление последнего чата.
- **Модели**: поповер с поиском, избранным и фильтрами; кэш списков (TTL 6 ч); кнопка «Проверить доступность» с бейджами; **автовыбор рабочей модели** при сбое.
- **Дизайн**: новая тёмная тема и светлая (авто по системе), аватары, индикатор набора, пустой экран с примерами, drawer на мобильных, safe-area, `prefers-reduced-motion`, фокус-стили; axe-core: 0 нарушений.
- **Горячие клавиши**: Ctrl+K, Alt+N, Alt+B, `/`, ↑, Esc.
- Черновик сообщения сохраняется при перезагрузке; список чатов синхронизируется между вкладками.
- **Картинки (vision)** для моделей с поддержкой изображений (OVH: Qwen2.5-VL-72B, Qwen3.8-27B, Qwen3.6-27B, Qwen3.5-9B; «свой» эндпоинт): скрепка, вставка, drag&drop, сжатие до 1024 px, до 3 шт.; в историю не сохраняются. Кнопка «Озвучить» (Web Speech API).
- Поиск по чатам теперь ищет и в тексте сообщений.
- Кнопка **«Продолжить»** для ответов, обрезанных по лимиту токенов; сообщение «нет интернета»; необязательный PWA (`manifest.webmanifest`, `sw.js`, офлайн-оболочка; запросы к API не кэшируются); ловушка фокуса в мобильном меню.

### Исправлено (по сравнению с v1)
- Разбор SSE: разрывы чанков посреди события, отсутствие пустой строки между событиями (ch.at), `[DONE]`, `reasoning`/`reasoning_content`/`<think>` больше не смешиваются с ответом.
- Повторы при 429/402/5xx с экспоненциальной паузой, `Retry-After` и видимым обратным отсчётом; лимит ожидания (`maxWaitMs`) теперь применяется к **каждой** попытке (раньше повтор после 503 мог ждать ~55 с, игнорируя порог автопереключения).
- Очередь и лимитер по провайдеру и модели (OVH: 2/мин/модель, Pollinations: 1/15 с, LLM7: 1 одновременно); режим сравнения запускает запросы со сдвигом.
- Стоп корректно сбрасывает состояние и обрывает запрос (для AI Horde — соединение со шлюзом); таймауты (общий и «нет данных»).
- AI Horde: повтор при разовом 406 «Not enough generations».
- Ответ, состоящий только из размышлений (лимит токенов), даёт понятную ошибку; в проверке доступности такая модель считается рабочей.
- Сообщения об ошибках по статусам (401/402/403/404/429/5xx, CORS/сеть) с кнопкой «Повторить».
- Статус «Загрузка модели…» у локальной модели гаснет с первым токеном.
- Тап-цели ≥ 44 px на сенсорных экранах, контраст (WCAG AA) в обеих темах, порядок заголовков.

- Обрыв соединения посреди потока больше не выдаётся за «ошибку CORS» — понятное сообщение, частичный ответ сохраняется.
- Markdown: экранирование обратным слэшем (`\*`, `\_`, `` \` ``) работало неверно — слэш оставался в тексте.

### Безопасность
- Markdown: весь HTML экранируется, ссылки только http/https/mailto с `rel="noopener noreferrer nofollow"`, картинок нет; автотест XSS.
- Ключи — только в `localStorage`, уходят только выбранному провайдеру; в репозитории нет секретов.
