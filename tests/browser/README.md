# Браузерные проверки (необязательно)

Требуют Chrome/Chromium и `npm i puppeteer-core axe-core` (в этой папке). Приложение должно быть запущено (`python3 -m http.server 8138` в корне проекта).

```
CHROME=/usr/bin/google-chrome APP_URL=http://127.0.0.1:8138/index.html node xss.cjs
```

| Скрипт | Что проверяет |
|---|---|
| `xss.cjs` | вредоносный markdown/ответ модели → нет скриптов, `on*`, `javascript:`; `window.__pwn` не задаётся |
| `axe.cjs` | axe-core: нарушения доступности в тёмной/светлой теме на всех вкладках |
| `keyboard.cjs` | Ctrl+K, Enter в поиске моделей, `/`, порядок Tab, фокус-стили |
| `a11y-drawer.cjs` | ловушка фокуса в мобильном drawer, `inert`, reduced-motion |
| `continue.cjs` | кнопка «Продолжить» для ответа, обрезанного по лимиту |
| `monkey.cjs` | «обезьяна»: случайные клики/клавиши 60–90 с со случайными 429/500 — ошибок страницы нет (`node monkey.cjs 390 844 60`) |
| `attach.cjs` | картинки: кнопка только у vision-модели, `image_url` в запросе, очистка превью |
| `cyber.cjs` | кибер-панк: кнопка в шапке (Enter/Space, `aria-pressed`), сохранение, возврат к прежней теме (авто/тёмная/светлая), класс ставится до первой отрисовки, axe-core в режиме кибер-панк, `prefers-reduced-motion` |
| `offline-sw.cjs` | service worker: офлайн-перезагрузка оболочки |

Сетевые ответы моделей в этих скриптах подменяются моками (кроме `keyboard.cjs`, где используется живой список моделей), поэтому лимиты сервисов не расходуются.
